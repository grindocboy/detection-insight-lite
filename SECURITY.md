# Security policy

Detection Insight Lite performs analysis locally in the browser. It has no
backend, analytics, authentication, cookies, or external API calls.

Do not paste production secrets, customer data, raw events, or proprietary
detection content into a public or shared browser session. The application can
flag common sensitive patterns, but it cannot guarantee that content is safe to
publish.

Please report vulnerabilities through a private GitHub security advisory. Do
not include live credentials or customer data in a report.
